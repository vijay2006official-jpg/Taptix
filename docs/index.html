Taptix Privacy Policy

Application: Taptix (com.example.taptix) • Version: 2.4 • Effective Date: November 2026

🔒 Core Privacy Commitment: Zero Remote Data Collection

Taptix operates on a strict local-first, on-device architecture. We do not maintain any user accounts, do not operate backend user databases, do not collect personal analytics, and do not transmit your screen data, trip details, or personal location off your device.

1. Overview

Taptix is an Android driver utility designed to assist ride-hailing and delivery partners (e.g., Uber Driver, Ola Driver, Rapido Captain, inDrive, Namma Yatri, Porter) by automating repetitive on-screen button taps hands-free while driving. This policy explains what information is processed by Taptix, why it is required, and how your privacy is protected.

2. Accessibility Service API Prominent Disclosure

Taptix utilizes Android's AccessibilityService API (com.example.taptix.service.AutoClickService) to provide hands-free driver automation.

  • Purpose: To detect incoming trip requests displayed on the device screen by supported driver apps and simulate a touch gesture on the driver's designated accept button.
  • Strict Local Processing: Screen nodes and text content inspected by the Accessibility Service are processed in real-time transient memory solely to identify configured keywords (e.g., "Accept", "Ride").
  • No Storage & No Transmission: Screen content, passenger details, addresses, and trip information are never recorded, logged to storage, or transmitted off your device.
  • Explicit User Control: The Accessibility Service requires voluntary activation in Android Accessibility Settings, displays a prominent in-app disclosure prior to enablement, and can be toggled off at any moment via the in-app switch or floating overlay.

3. Data Processed Locally on Your Device

Category Source / Type Storage & Lifecycle
Location Coordinates GPS / Network Location for Map Zone geofencing. Evaluated strictly on-device against driver-defined circular zones. Never transmitted to any remote server or logged persistently.
Driver Preferences App settings, audio alerts, click delay, and target coordinates. Saved in local Android SharedPreferences encrypted private storage. Never synced externally.
Activity History Local event counter (App name, timestamp, Accepted/Rejected status). Stored in private on-device storage. Automatically capped at 150 entries and purged after 7 days. Does not contain passenger or financial details.

4. Data We Never Collect or Share

Taptix has zero technical capability or interest in collecting:

  • Passenger identities, phone numbers, pickup/drop-off addresses, or route recordings.
  • Fare earnings, banking info, or payment credentials.
  • Microphone recordings, voice conversations, photos, or screenshots (microphone permission is entirely removed).
  • Device identifiers (IMEI, Advertising ID, MAC address, serial number).
  • Browsing history, contact lists, SMS messages, or cross-app usage telemetry.

5. Network Communications & SDK Transparency

Taptix transmits zero bytes of user data. Network communication is strictly confined to the following system and utility functions:

  • Map Zone Tiles: When viewing the Map Zone screen, public OpenStreetMap tile servers are contacted to render map imagery. No user identifier is sent.
  • Google Play In-App Updates: The official Google Play In-App Update API checks the Play Store to notify drivers when a new stable version is available.
  • GitHub Releases Update Check: For non-Play standalone builds, the app connects to GitHub API over HTTPS to compare version tags.
  • Zero Third-Party Trackers: Taptix contains no third-party analytics libraries (no Firebase Analytics, Flurry, Adjust, or AppsFlyer), no crash monitoring SDKs with data egress, and no advertising networks.

6. Android Permissions Required

Permission Technical Purpose
BIND_ACCESSIBILITY_SERVICE Detects accept buttons on supported driver apps and simulates user taps.
SYSTEM_ALERT_WINDOW Displays the persistent floating control overlay above partner apps.
FOREGROUND_SERVICE_SPECIAL_USE Ensures the floating overlay service remains responsive while driving.
POST_NOTIFICATIONS Displays the required persistent foreground service indicator and safety alerts.
ACCESS_FINE_LOCATION Evaluates local geofence entry/exit for user-defined Map Zones.
VIBRATE Provides physical haptic confirmation when a ride request is accepted.
INTERNET Fetches map tiles in MapZone and checks for app updates.
REQUEST_IGNORE_BATTERY_OPTIMIZATIONS Prevents the OS from abruptly suspending automation during active shifts.

7. Data Retention & Deletion

Because all data resides exclusively on your local device:

  • You can purge all history logs anytime via Settings > Clear Logs.
  • Clearing app data or uninstalling Taptix immediately and permanently deletes all preferences, zone coordinates, and logs from your device.
  • No remote deletion request is necessary because no remote data exists.

8. Children's Privacy

Taptix is built exclusively for licensed professional commercial drivers (18 years of age or older). We do not knowingly solicit or collect data from children under 13.

9. Policy Updates

Material updates to this policy will be documented in release notes and posted to our public GitHub repository prior to application updates.
